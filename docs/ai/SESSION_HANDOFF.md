Zeit pausiert bis SYNC-001 (`DoSingleTick`-Sperre). Hauptmenü verwirft das Spiel ohne offenes Fenster. ADR 0023, Verifikation `docs/verification/2026-10-15-game-start.md`.
- **SETUP-005, Fehlerbehebung (2026-10-16):** Der Host wartete nach „Start“ ohne offenes Fenster auf den Server. Das Hauptmenü verwarf die Einrichtung, und vanilla startete ein Spiel mit Zufallsfiguren an einem Zufallsort. Jetzt hält das Multiplayer-Fenster das Spiel, solange die Anfrage läuft. Ohne `GameInitData` bricht die Mod ab. Der Selbsttest prüft das Halten, die gelandeten Figuren und den Ort (ohne Fenster FAIL, mit Fenster PASS). Verifikation: `docs/verification/2026-10-16-start-keeps-setup.md`. Im installierten Mod-Ordner liegt noch eine alte `Multiplayer.Foundation.Session.dll`; sie wirft beim Start eine `TypeLoadException` und gehört entfernt.
